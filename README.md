# Devlet Yönetim Paneli V7

GitHub Pages için index.html ve config.js dosyalarını repository ana dizinine yükle.
Supabase SQL Editor içinde schema.sql dosyasını bir kez çalıştır.
GitHub Pages: Settings > Pages > Deploy from branch > main / root.
Siteyi yayınladıktan sonra Ctrl+F5 yap.

Bu sürüm tarayıcıda yalnızca Supabase Publishable Key kullanır. service_role veya sb_secret kullanma.
